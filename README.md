# Xuan Luo academic website

A dependency-free, single-page academic website prepared for GitHub Pages. The root address is the Research page; there are no separate Home or Contact pages.

## Publish as a personal GitHub Pages site

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload everything in this folder to the root of that repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. The site will be available at `https://<your-github-username>.github.io/` after GitHub finishes publishing.

## Before publishing

- Confirm the English and Chinese name, current title, institution, and location.
- Replace the email address if a university email is preferred.
- Add a current CV only if you later decide to provide a public download.
- Confirm every publication status, year, author order, DOI, and PDF version.
- Add optional GitHub, Google Scholar, ORCID, and institutional profile links.
- If using a custom domain, create a file named `CNAME` containing only that domain.
